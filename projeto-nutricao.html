Sobre a Solução

Protótipo interativo desenvolvido em Python e Streamlit para estimativa de necessidades energéticas e recomendação nutricional inteligente. A solução integra uma interface conversacional em linguagem natural capaz de interpretar dados antropométricos, objetivos e preferências do usuário para calcular suas demandas calóricas diárias. Utilizando os dados de composição da Tabela TACO (UNICAMP) associados ao algoritmo de clusterização K-Means, o sistema segmenta e seleciona perfis alimentares adequados. Para garantir precisão semântica e contextualização, o pipeline emprega a API de Embeddings da OpenAI (ChatGPT), alinhando de forma mais coerente as restrições e preferências do usuário às combinações de alimentos recomendadas, gerando sugestões personalizadas de forma rápida, intuitiva e consistente.

Tecnologias Utilizadas

  • Streamlit
