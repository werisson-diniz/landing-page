Sobre a Solução

Protótipo Este código implementa um sistema comparativo de diagnóstico médico preliminar por similaridade de texto. A ideia principal é receber a descrição textual dos sintomas de um paciente e compará-la com uma base de dados pré-existente de casos clínicos para sugerir os diagnósticos mais prováveis, contrastando abordagens clássicas e modelos modernos de Processamento de Linguagem Natural (PLN). Geração de Representações Vetoriais (Embeddings): O código gera vetores representativos para os sintomas da base de dados através de três famílias principais:TF-IDF: Método estatístico baseado em frequência de palavras. SBERT Multilingue: Utiliza o modelo paraphrase-multilingual-MiniLM-L12-v2 para capturar a semântica geral das frases em vários idiomas. PubMedBERT: Utiliza o modelo biomédico NeuML/pubmedbert-base-embeddings, focado no vocabulário e contexto da área da saúde.

Tecnologias Utilizadas
